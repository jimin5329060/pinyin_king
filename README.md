# 拼音王（pinyin_king）产品需求文档 PRD

> 版本：v1.0（MVP 草稿）
> 状态：需求评审稿
> 最后更新：2026-10-15
> 技术栈：Flutter（Android / iOS / Linux / macOS / Web / Windows）
> 适合读者：产品、设计、研发、测试

---

## 1. 背景

### 1.1 问题
幼小衔接阶段（3–5 岁）儿童在拼音启蒙时，最关键的诉求是**把音发准、避免失真**。现有市面产品（洪恩拼音、帮帮拼音、悟空拼音等）普遍存在：
- 纠音反馈机械、只报错不教舌位；
- 部分产品在易混音（如 `o` 的发音口径）上失真，被家长投诉；
- 几乎全部是纯移动端 App，缺少适合家长在大屏（桌面 / Web）辅导、查看的载体。

### 1.2 我们的定位
**不做 AI 评测、不做游戏化军备竞赛**，做一款"方便大家用的权威拼音教材工具"：
- 以**标准音为锚**（权威音源，统一口径）；
- 以**录音对比为核**（儿童录自己的音，自行对照标准音，靠耳朵判断）；
- **完全免费**，**不做线上发布**，仅线下分发。

参考路线为竞品调研中确认的"路线 C 收敛版"。

---

## 2. 目标

### 2.1 产品目标
- G1：让 3–5 岁零基础儿童能够便捷地听到**标准、统一的拼音读音**。
- G2：提供**录音—对比**闭环，帮助用户自我校准发音（无评分、无 AI 判定）。
- G3：以一套代码覆盖六端（Android / iOS / Linux / macOS / Web / Windows），降低分发与维护成本。

### 2.2 成功指标（MVP 口径）
- S1：单音标准音播放成功率 ≥ 99%（各端）。
- S2：录音采集成功率 ≥ 95%（各端，含首次授权后）。
- S3：标准音与录音的 A/B 切换播放延迟 < 300ms。
- S4：核心流程（浏览→听→录→对比）在六端均可走通。

> 注：MVP 阶段不收集用户账号与行为数据，指标以"本地可用性 + 自测"为主，不依赖线上埋点。

## 3. 用户与用户故事

### 3.1 角色
| 角色 | 说明 | 主要诉求 |
|---|---|---|
| 学龄前儿童（3–5 岁） | 零基础使用者 | 大字、大按钮、能听能录、操作简单 |
| 家长 / 老师 | 辅助者 | 大屏辅导、标准音来源可信、易混音有说明 |

### 3.2 用户故事
- US1：作为儿童，我想点一下就能听到某个拼音的**标准读音**，这样我能跟着学。
- US2：作为儿童，我想录下自己读的音并和**标准音并排听**，这样我能判断自己读得对不对。
- US3：作为家长，我想在大屏（macOS / Windows / Web）上给孩子放标准音、看拼音，这样辅导更方便。
- US4：作为家长，我想知道这个音的**标准口径来源**，尤其是易混音（`o`、平翘舌、前后鼻音），这样我放心。
- US5：作为儿童，我想做一点**拼读练习**（如 b-a→ba），巩固单音。

## 4. 范围

### 4.1 In Scope（MVP）
- 拼音总览 / 分组浏览（声母 / 韵母 / 整体认读 / 字母表）
- 单音学习页：字形 + 标准音播放（可循环）
- 录音对比页：录制、听标准、听自己、A/B 切换（不评分）
- 拼读练习：声母+韵母组合，播放标准拼读音 + 录音对比
- 我的录音本：本地保存历史录音
- 关于 / 标准说明：来源标注、易混音口径提示

### 4.2 Out of Scope（v1 不做）
- 语音评测 / AI 打分（无预算）
- 账号系统、云端同步、商业化
- 游戏化剧情、IP、儿歌绘本矩阵
- Python 后端（MVP 纯本地资源；后续 OTA 音频包更新再引入）
- 线上发布（App Store / 各应用市场）

## 5. 功能清单（EARS 表述）

> EARS 标注：U=Ubiquitous（始终满足）；E=Event-driven（事件触发）；W=Unwanted（异常/故障）；S=State-driven（状态下）；O=Optional（可选）。

### FR-01 拼音总览与分组浏览
- **U** 系统应提供按分组展示拼音的入口，分组至少包含：字母表、声母表、整体认读、单韵母、复韵母、前鼻韵母、后鼻韵母。
- **E** 当用户选择某分组时，系统应展示该分组下全部拼音条目的卡片列表（按 `seq` 排序）。
- **E** 当用户点击某条目卡片时，系统应进入该条目的单音学习页。

### FR-02 单音学习页（标准音播放）
- **U** 系统应能为每个拼音条目加载并播放其对应的标准音音频（`assets/audio/<分组>/<文件>.mp3`）。
- **E** 当用户点击"播放标准音"时，系统应播放对应音频；播放中再次点击，系统应停止或重头播放（二选一，交互说明约定为"重头播放"）。
- **O** 在"循环播放"开启时，系统应在当前音频播放结束后自动重播，直到用户关闭循环或离开页面。
- **W** 若音频资源缺失或加载失败，则系统应提示"音频暂不可用"并禁用播放按钮，不得崩溃。

### FR-03 录音对比（核心）
- **E** 当用户点击"开始录音"时，系统应请求麦克风权限（首次）并开始采集音频。
- **S** 在录音进行中，系统应持续显示录音状态（如时长 / 波形占位），并允许"停止录音"。
- **E** 当用户停止录音后，系统应保存本次录音到本地（应用私有目录），并允许回放。
- **E** 当用户触发"听标准音 / 听我的音"切换时，系统应在 < 300ms 内播放对应音频（A/B 快速切换）。
- **W** 若用户拒绝麦克风权限，则系统应提示需在系统设置中开启，并禁用录音功能，但标准音播放仍可正常使用。
- **W** 若录音设备被占用或采集失败，则系统应提示"录音失败，请重试"，不写入损坏文件。

### FR-04 拼读练习
- **O** 在拼读练习模块，系统应提供声母+韵母的组合（如 b-a→ba），并播放标准拼读音。
- **E** 当用户在拼读练习页点击某组合的标准音时，系统应播放该组合的标准拼读音。
- **E** 当用户在拼读练习页完成录音后，系统应提供与 FR-03 一致的对比回放能力。

### FR-05 我的录音本
- **U** 系统应将用户每次成功录音保存到本地，并在录音本中按时间倒序列出。
- **E** 当用户点击某条历史录音时，系统应回放该录音。
- **E** 当用户删除某条录音时，系统应从本地移除该文件并刷新列表。
- **W** 若本地录音文件被外部清理（读取失败），则系统应跳过该条目并提示，不崩溃。

### FR-06 关于 / 标准说明
- **U** 系统应在"关于"页标注标准音来源与口径（建议统一采用普通话水平测试 PSC 一级甲等标准）。
- **S** 在展示易混音（`o`、平翘舌、前后鼻音）条目时，系统应提供一句口径说明文字。

---

## 6. 关键流程说明

### 6.1 主流程：听标准音 → 录音 → 对比
```
[总览/分组] → [单音学习页]
   ├─ 点击播放 → 播放标准音
   └─ 点击录音 → (授权麦克风) → 录音中 → 停止 → 保存
                       │
                       └→ [对比] 听标准 / 听自己（A/B 切换）
```

### 6.2 首次麦克风授权流程（按端）
- Android / iOS：系统弹窗授权，拒绝后引导至系统设置。
- macOS / Windows / Linux：首次使用录音时请求，桌面系统通常默认允许应用级麦克风。
- Web：浏览器弹窗授权（HTTPS 或 localhost 环境）。

---

## 7. 交互说明（低龄适配）

- 播放 / 录音按钮**尺寸放大**、间距宽松，避免误触。
- 录音交互建议"按住录、松手停"或"大字开始/停止"二选一，以家长辅助操作为主。
- 不做评分、不做对错判定；对比靠"听"与"并排"，避免给低龄儿童挫败感。
- 字号大、对比强；避免复杂二级菜单。
- 桌面 / Web 端支持窗口响应式布局（手机竖屏 + 桌面窗口两档）。

## 8. 数据口径

### 8.1 资源索引（manifest.json）
音频资源通过 `assets/audio/manifest.json` 索引，结构如下：
```json
{
  "version": 1,
  "source": "标准音来源说明",
  "total": 212,
  "groups": ["字母表","声母表","整体认读","单韵母","复韵母","前鼻韵母","后鼻韵母"],
  "items": [
    { "id":"单韵母_01_a_1", "group":"单韵母", "letter":"a", "tone":1, "seq":1, "asset":"assets/audio/单韵母/01_a_1.mp3" }
  ]
}
```
- `tone`：1–4 对应一声到四声；`null` 表示无声调（声母 / 字母）。
- `letter`：`ü` 统一转写为 `v`（如 `lv`）。
- 命名规则：`序号_基础字母[_声调].mp3`，保证唯一、可排序、零重名。

### 8.2 录音存储
- 路径：应用私有目录（`path_provider` 的 `appDocumentsDirectory`）。
- 格式：优先 m4a / aac；Web 端受浏览器限制可能回退为 wav，需做兼容。

## 9. 权限与合规

- **麦克风权限**：仅在用户主动触发录音时请求；拒绝后给出明确引导，不强制。
- **儿童个人信息保护**：MVP 无账号、无上传、无行为采集；录音仅存本地。后续若引入云端，须单独隐私政策。
- **音源版权（重要待确认）**：当前 212 个标准音来自第三方网站，仅用于本地整理 / 原型；正式线下分发前须确认授权，或替换为**自录 PSC 一级甲等标准音**（版权归己）。
- **标准音源采集地址（参考）**：
  1. 首页 / 字母表：`https://www.xdf.cn/zhuanti/suyang_pinyin/index.html`
  2. 声母表：`https://www.xdf.cn/zhuanti/suyang_pinyin/pages/shengmu.html`
  3. 韵母表：`https://www.xdf.cn/zhuanti/suyang_pinyin/pages/yunmu.html`
  4. 整体认读：`https://www.xdf.cn/zhuanti/suyang_pinyin/pages/zhengti.html`
- **宣传口径**：避免"抢跑 / 超前教学"等表述，定位为"拼音教材辅助工具"。

## 10. 异常与边界场景

- 音频资源缺失 → 提示并禁用播放，不崩溃（FR-02-W）。
- 麦克风拒绝 / 占用 / 失败 → 分级提示，录音功能降级，标准音不受影响（FR-03-W）。
- 本地录音文件被清理 → 跳过损坏条目（FR-05-W）。
- Web 端非安全上下文（非 https/localhost）→ 录音不可用，给出提示。
- 低龄误操作（连续快速点击播放）→ 同一音频重入应安全（先停后播或忽略重复触发）。

## 11. 埋点需求（MVP 最小化）

MVP 阶段**默认不采集任何用户数据**（契合"免费、无账号、线下分发"）。仅建议在代码层保留可选的本地使用统计开关（默认关），用于自查哪类拼音被练习最多，便于后续内容优化。**不默认上报、不上传云端**。

## 12. 验收标准

| 功能 | 验收要点 |
|---|---|
| FR-01 总览/分组 | 七组均可见，条目按 seq 排序，点击进入详情 |
| FR-02 标准音 | 各端点击即可播放；缺失资源有提示不崩溃 |
| FR-03 录音对比 | 六端均可授权并采集；A/B 切换 < 300ms；拒绝权限有引导 |
| FR-04 拼读练习 | 组合可播标准拼读音，可做对比回放 |
| FR-05 录音本 | 录音可保存/回放/删除；损坏文件跳过不崩 |
| FR-06 说明 | 来源标注可见；易混音有口径说明 |

## 13. 技术约束与依赖

- 前端：Flutter 3.41.6，目标六端全开。
- 录音：`record ^5.2.1`（六端插件：android/darwin/linux/web/windows 均已引入）。
- 播放：`audioplayers ^6`，波形可视化 `audio_waveforms`（仅移动端，桌面/Web 降级为纯听感对比）。
- 存储：`path_provider ^2.1.6`。
- 资源：212 个 mp3 已入库 `assets/audio/`，由 `pubspec.yaml` 的 `assets` 注册。

## 14. 风险与待确认

1. **音源版权（最高优先）**：第三方素材仅本地用，正式分发前须替换为授权音或自录 PSC 标准音。
2. **易混音口径**：`o` 等发音各家不一，需在产品内明示采用 PSC 一级甲等标准。
3. **Web 录音格式兼容**：需实测浏览器编码支持，必要时回退 wav。
4. **六端一致性**：录音/播放在各端的权限模型与格式差异需在真机/真浏览器验证。
5. **flutter SDK 位置**：当前装在 `~/Desktop/flutter`（临时），建议迁移至固定目录。
